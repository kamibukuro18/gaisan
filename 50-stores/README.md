# 50 STORES PROJECT の更新

`stores.json` の `displayed` に実際に展示している店舗の合計を入れます。`target` は目標数です。公開の許可がない店舗については合計にだけ含め、このフォルダやコミット履歴に店舗名・写真・位置情報を追加しないでください。

店舗名・エリア・写真の公開が許可された店舗のみ、`stores` に追加します。JSON の項目は `approved`（true）、`number`（公開店番号、重複不可）、`name`、`area`、`photo`（photos/ 内のファイルパス）、`alt`（設置状況が伝わる説明）が必須です。展示開始日 `date`（YYYY-MM-DD）、店舗情報リンク `website`、Google マップの共有リンク `directions` は公開できるものだけを任意で追加します。写真は店内で絵が見える実写真を使い、公開許可・写り込み・位置情報を確認します。

地図掲載も許可された国内店舗のみ、正確な `lat`、`lng`（10進数）を追加します。地図を表示するボタンを押した時だけ Leaflet 1.9.4 と国土地理院の淡色地図を取得します。地図を使わなくても、公開店は一覧とギャラリーから確認できます。

ビルド不要です。ローカル確認はリポジトリのルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/50-stores/` を開いてください。
