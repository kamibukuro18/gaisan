# STAR FINCH — FLUX 10 / NOCTURNE ENGINE

## 今回の追加
- 1→2→3→4面のキャンペーン。3面撃破後に3.5秒の休憩、負荷冷却、ボム1個補給。スコア・残機・武器・パワーをそのまま4面へ持ち越します。
- 4面「NOCTURNE ENGINE」：78ゲーム秒の道中。紫の機械回廊、回転する背景歯車、予告狙い弾と欠けた輪の敵編隊。
- 道中は15秒ごとに5秒の射撃休止。新しい敵と射撃を止め、冷却と回収の時間を残します。既に飛んでいる弾は消えません。
- ボス「ECLIPSE REGENT」：HP820。CLOCKWORK PETALS／ECLIPSE RAILS／PENDULUM WINGS／MIDNIGHT CROWNの4弾幕。各6.2秒中2.4秒は新規射撃なし。レール攻撃には幅70pxの固定安全レーンがあります。
- HP半分以下で0.85秒予告の固定照準5発を追加。予告を見て移動できます。ボムと休止は予告も取り消します。
- 専用チップチューン2曲「Nocturne Engine」「Eclipse Regent」。既存音量とパルス/三角波/ノイズ構成に合わせたオリジナル曲です。
- 4面撃破で最終クリア。Rは1面から再スタート。

## 維持したルール
初期ボム1、3種の武器とチャイム、負荷による段階的スロー・コマ落ち・BGM速度低下、100%を連続3秒維持するとクラッシュして2.5秒の故障音、既存の被弾演出。1〜3面の攻撃パターンと数値は変更していません。

## 遊び方
Godot 4.6.3でproject/project.godotをインポートしてF5。またはWeb ZIPを展開して python3 play_web.py を実行します。WebGL2対応ブラウザーが必要です。HTMLのダブルクリックでは動きません。

Enter/Z：開始、矢印/WASD：移動、Shift：低速、X：冷却、C：ボム、P：停止、R：最初から、M：消音。
