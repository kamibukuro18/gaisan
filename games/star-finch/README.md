# STAR FINCH — FLUX CIRCUIT

ファミコン／スーパーファミコン寄りのドットで遊ぶ、オリジナル弾幕シューティング。PC向けの横長画面で、左が縦スクロールの戦闘フィールド、右がスコア・武器・負荷メーターです。

遊ぶ：https://pixel-burst-shooter.gaisandesu.chatgpt.site （利用者限定の配布）

## 2ステージ構成

1面ボス撃破後、そのまま新しい2面「EMBER FOUNDRY」へ進む2ステージ構成になりました。
橙・金・シアンの宇宙鍛造所、新しい敵編隊、太陽核を持つボス「SOLAR WARDEN」、道中・ボスそれぞれの新BGMを追加。既存の負荷管理・ボム・巨大カウント・2.5秒の故障音は維持しています。

## 今回の難度調整（FLUX 08）

2面だけ、弾の狙い方を少し強化しました。1面・ボスHP・初期ボム1・負荷管理の数値は変更していません。
- 道中の敵は射撃前に小さな照準マーカーで位置を固定。小型敵の左右に分かれていた2発のうち1発が狙い弾になり、同じ場所に留まるより横移動が有効です
- 編み込む敵は、飾り状の弾流と自機狙いの扇を交互に撃ちます。弾数は増やさず、射撃間隔は少し広げています
- 2面の弾速を約1割上げました。予告も弾もゲーム時間で進むため、高負荷時にも対応時間が残ります
- SOLAR WARDENは残HP半分でPHASE 2。左右交互の「LOCK」が0.65ゲーム秒予告してから3発を撃ちます。照準は予告開始時の位置に固定されるので、ロックを見て切り返しましょう
- 道中の3.6秒休止、ボスの1.7秒VENT WINDOW、隙間レーンは維持。休止やボム中は予告中の横攻撃も取り消します

照準は位置の予告です。弾が到着するまでの間は、前の弾にも注意してください。

## 最初の1分

1. Enter / Z / Space / 画面クリックで開始。最初からオート連射です。
2. 矢印 / WASDで移動。細い隙間はShiftを押しながら低速移動。
3. 浮いているチャイムを撃つと色が変わります。欲しい色でXを押して射撃を止め、近づいて回収。
4. 危ないときはCでボム。敵弾を一掃できますが、負荷が急上昇し余熱も残ります。
5. 右の負荷が黄色になったらX長押しで冷却。100%に連続3秒留まると残機に関係なく過負荷ゲームオーバーです。
6. ゲーム内時間52秒の道中の後にIRIS MOTHが登場。倒すと休憩を挟んで2面へ。2面のSOLAR WARDENを倒すと最終クリアです。低負荷ほど速く進み、各ボス撃破で最大6,000点のFLOWボーナス。

## 2面への進み方

1面ボスを倒すと中間ボーナスを獲得し、3.5秒の安全な休憩へ入ります。
- スコア、残機、シールド、武器・レベルをそのまま継承。残機の自動回復はありません
- 熱とボムの余熱は0へ。ボムを1発補充（最大3発）
- 戦闘中の弾や敵を消去し、装備を保ったまま2面の開始位置へ
- Pで休憩の秒数も停止。Rならいつでも1面・初期ボム1発からやり直し

2面の道中は64ゲーム秒。12秒周期のうち後半3.6秒は新しい敵の出現と射撃が休み、HUDにFIRE BREAK / COOL NOWと表示します。すでに飛んでいる弾は残るので、避けながらXを使う好機です。
重くなったままでは実時間が長くなるため、2面連続の所要時間は遊び方で変わります。通常資源の入力シミュレーションで、冷却と移動を使う複数方針の最終クリアを確認しています。人間の平均成績を表すものではありません。詳細はQA_REPORT.mdを参照してください。

### SOLAR WARDENの4つの弾幕

- SOLAR ROSETTE：橙とミントの5弁の花。花びらの間に広い通路
- FORGE LANES：縦の弾雨。シアンの点線とGAP表示で、次の弾雨の開いたレーンを予告。前のパターンの残弾には注意
- TWIN GEARS：左右の回転歯車。下向きの歯を抜いて通路を残す
- CROWN SWEEP：左右の扇状攻撃。中央寄りの空間を読みながら移動

新ボスは4.8ゲーム秒のまとまりごとに1.7秒の射撃休止があり、開始前0.55秒も予兆の間です。休止中も攻撃は当たります。冷やすか、攻めて削るか、ボムで切り抜けるかを選べます。
2面を直接選ぶ通常メニューはありません。最初から1→2と続けて遊ぶ設計です。

## 操作

- 移動：矢印キー / WASD
- 低速移動・当たり判定表示：Shift長押し
- 射撃：初期設定はオート。FでオートON/OFF。手動はZ / Space長押し
- ボム：Cを押す。開始1発・最大3発。右パネルのC BOMB行をクリックしても発動
- 冷却：X長押し。射撃を止め、毎秒22ポイント冷却（ボム余熱中は差し引き毎秒10ポイント）
- 一時停止・復帰：P / Esc、または右パネルのPボタン
- 即リトライ：R、または右パネルのRボタン。高負荷のコマ落ち中も即時有効
- 消音：M、または右上のM
- マウス・タッチ：フィールドを押しながらドラッグで移動・射撃。右の負荷メーター付近をクリックすると冷却ON/OFF

実機ファミコンROMではなく、Godot 4.6.3製ゲームです。内部解像度は512×320、nearest補間のドット表示。

## 撃って選ぶ4色チャイム

チャイムはシアン → 紫 → 金 → 緑 → シアンと巡回します。連射で一瞬に色が飛ばないよう、変更後450msは色が変わりません。撃つと少し跳ね上がり、射撃を止めればゆっくり降りてきます。天井近くでも自機が届きます。

- シアン：TWIN。直線2連射、低負荷。同色をもう1つ取ると4連射
- 紫：FAN。5方向の拡散、やや高負荷。同色で7方向へ
- 金：OPTIONS。2つの随伴機から追加射撃、高負荷。同色で随伴機が4つに
- 緑：COOL + SHIELD。負荷を38下げ、シールド1回分とボム1発を追加。今の武器は維持。シールドは最大2回分、ボムは最大3発

違う武器色を取ると、その武器のLv.1に切り替わります。武器レベルは最大2。
シールドがない状態で被弾すると残機が減り、武器レベルが1に戻ります。被弾後は無敵時間と敵弾消去があり、連続被弾を防ぎます。約65msのhitstop、約0.55秒の回復スロー、破片・リング・画面揺れを伴います。HUDは揺らしません。

## NOVA BOMB

Cで画面内の敵弾を一掃し、雑魚に20ダメージ、ボスに80ダメージ。消した敵弾は1発3点。自機に1.35秒の無敵が付き、発動直後0.55秒は新しい敵弾も抑えます。
開始1発、最大3発。緑チャイムで補充できます。長押しでは1発だけ、発動後0.9秒は再発動不可。一時停止中・クリア後・残数0では消費しません。Rで新しい1発に戻ります。

代償は負荷+40と、実時間3.2秒にわたる毎秒12ポイントの余熱。敵弾を消してもすぐ軽くなりません。画面の爆発とリングも重いゲーム時間で動きます。
余熱中もXなら差し引き毎秒10ポイントずつ冷却。緑チャイムの冷却も有効です。ボムは危機脱出の切り札なので、使えば必ず最速になるわけではありません。
ポーズで余熱や無敵の時間も止まり、リトライやクリアへ残りません。大きな全画面フラッシュや本物のCPU停止は使いません。

## 徐々に重くなる、ファミコン風の疑似処理落ち

右のSYSTEM LOADはゲーム内の仮想メーターです。実際のCPU使用率や端末温度ではありません。
画面内の弾・敵・爆発、強い武器、連続撃破が増えると上がります。前版より早めに重くなり、TWIN連射でも10〜20秒ほどで変化を感じられる調整です。負荷が上がるほど、自機も敵も弾も同じ時計で徐々に遅くなり、画面内の動きがカクカクしてきます。

- 負荷0〜15%：速度100%。低負荷では戦闘世界を毎秒60回更新
- 負荷50%：速度約75%、更新は約31回/秒
- 負荷75%：速度約46%、更新は約18回/秒
- 負荷100%：速度32%、基準更新は約15回/秒。不規則なホールドを混ぜます。100%に連続3秒滞在すると過負荷でゲームオーバー
- 間の値も滑らかに変化。HUDのSPEEDはゲーム内速度、STEPは不規則な間隔の基準更新頻度で、実際のブラウザFPSの計測値ではありません

射撃を止めるだけでも徐々に冷却。Xなら毎秒22ポイント冷却し、緑チャイムなら一度に38ポイント下がります。冷却すると速度と更新頻度が戻ります。
自機だけが高速に動けるスローモードではなく、射撃・自機・敵弾・進行が一緒に重くなります。強い武器を使い続けるか、いったん冷やしてテンポとFLOWボーナスを取り戻すかが選択です。

入力自体は毎フレーム読み取り、短いキー操作も次の世界更新まで蓄積します。重くなるほど長短の待ちが混ざり、最高負荷の目標ホールドは30〜120ms（実際の表示フレーム単位に丸まります）。通常の均等な15Hz更新より、短く固まってから位置が進む感覚を強めています。冷却、HUD、ポーズ、リトライは間引かず反応します。
画面を保持している間は自機・敵・弾の位置も保持し、描画の裏で進みません。更新時の短い軌跡を表示し、前の位置から今の位置までの相対移動区間で衝突を確認することで、速い弾が対象を飛び越えて無視されるのを防ぎます。異常に長いdeltaでも1回の世界更新を75ms以下に抑え、移動入力も同比率に制限します。溜まった射撃を一度に再生しません。音楽も負荷に合わせて滑らかに遅くなり、ピッチが下がります。再生速度の下限は62%、冷却で100%へ復帰します。効果音と故障音は原速です。
旧版の一時的なCORE HALTや1,500点減点はありません。実際のCPUを過負荷にする仕掛けではありません。

### 100%のまま3秒でCORE OVERLOAD

メーターが100%になると中央に大きく3→2→1、100% CORE DANGER、HOLD X TO COOLと赤い四隅の枠を表示。秒の節目だけ数字と装飾を少し拡大し、弾幕の大部分と下側の自機は見える配置です。高速白フラッシュやストロボは使いません。右HUDにも残り秒数を表示します。遅いゲーム時間ではなく実プレイ時間で連続3秒を計測します。Pで一時停止中は進みません。100%未満へ下がればタイマーは0へ戻り、また100%になったときは3秒から数え直します。99.9%は99%表示なので、表示だけ100%になる矛盾はありません。Xの冷却は同じフレームの死亡判定より先に反映します。

時間切れではBGMとSEが止まり、控えめな2.5秒のピー音、水平の画面乱れ、CORE OVERLOAD表示で終了します。ピー音もM消音に従い、その後は無音です。Rを押すとピー音は即停止します。残機死は大きなリング爆発とスローで別演出。いずれもRで即リトライでき、死亡演出中はPも使えます。ゲームアプリ自体は固まりません。

## 弾幕とスコア

ボスは花びら、螺旋、扇、交差の4パターンを巡回。敵弾の丸い輪郭と、自機弾の細長い形を分けています。
自機の被弾判定は中央の小さな点付近（半径2.2px）。Shift中は目印が表示されます。

連続撃破でCHAINと最大8倍の得点倍率。結晶は自動回収。25撃破ごとに短いOVERDRIVE。
撃破や爆発による負荷も同じ連続的な疑似処理落ちに反映されます。FLOWボーナスは各ボスで6,000×(1−その時点の平均負荷/100)、端数四捨五入。2面合計最大12,000点、最終画面のFLOW表示は最後のボス分です。急な減点はありません。

## Webビルドと書き出し

別添Web ZIPをHTTPサーバーで配信して使えます。file://のダブルクリック起動には対応していません。
Python 3があればWebフォルダで `python3 -m http.server 8000`、ブラウザで http://localhost:8000/ を開きます。
WebAssemblyとWebGL 2.0が必要。single-thread書き出しなので特殊なクロスオリジン分離ヘッダーは不要です。
音は開始操作後に鳴ります。プライベートモードなどでは記録を維持できない場合があります。Mac Safari/iPhone/Androidの実機検証は未実施です。

エクスポートにはGodot 4.6.3公式Export Templatesをインストールしてください。出力フォルダを作ってから：

- Web：`godot --headless --path project --export-release Web`
- Linux：`godot --headless --path project --export-release Linux`

Godot本体とExport Templatesは同梱していません。

自動検証：`godot --headless --path project --script res://tests/smoke.gd`、`godot --headless --path project --script res://tests/balance_v7.gd`。後者の結果は `qa/balance_v7.json` に出力します。難度比較は `godot --headless --path project --script res://tests/balance_v8.gd`、追加回帰は `godot --headless --path project --script res://../qa/balance_v8_mechanics.gd`。それぞれ `qa/balance_v8.json` と `qa/balance_v8_mechanics.json` に記録します。

## 新しい音楽

- 道中：Skyfire Velocity。約174 BPM、32小節・44.144秒。走るbass/drums、主題から対旋律、高音のサビへ進むチップロック
- ボス：Crimson Overdrive。約186 BPM、24小節・30.972秒。高速bassと別の主題
- 2面道中：Ember Circuit。168 BPM、約40秒。機械的な3+3+2アクセント、短い金属音、E minor/Dorianの独自主題
- 2面ボス：Solar Warden: Ignition。192 BPM、40秒。F# minorの別主題と速い駆動感
- NOVA BOMB：noiseの爆発、下降するチップ音、低音の余韻

すべてオリジナルの合成音です。第三者の曲・録音・サンプル・soundfontは使用していません。BGMはOGGのシームレスループ。高負荷では0.22秒の平滑化を挟み、BGMの速度とピッチを100〜62%へ変えます。Mで一括消音できます。過負荷ゲームオーバー時は音楽を止め、2.5秒の故障音へ切り替えます。
BGMを前に出し、連射SEの音量を控えめにしました。ポーズ時は曲も一時停止し、リトライ時は通常速度で道中曲の頭から再生します。ボス登場時は0.28秒の警告アルペジオを挟み、独立したボス専用曲へ切り替わります。音量は4曲とも同じです。1面後の休憩では中間ジングルを鳴らし、2面開始で新しい道中曲に切り替わります。
